# 实验：全连接神经网络

## 一、实验目的
1. 理解多层感知机（MLP）的基本原理，掌握全连接层、激活函数的作用；
2. 熟练使用PyTorch框架完成数据集加载、网络搭建、前向传播、反向传播与参数更新；
3. 掌握DataLoader、梯度清零、损失计算、优化器迭代、模型评估的标准训练流程；
4. 观察损失函数与分类准确率随训练轮次的变化规律，分析模型收敛特性；

## 二、实验环境
- 编程语言：Python 3
- 深度学习框架：PyTorch、torchvision
- 开发工具：Jupyter Notebook
- 运行设备：CPU
- 依赖库：numpy、matplotlib

## 三、实验原理
### 3.1 MNIST数据集
MNIST是手写数字灰度数据集，包含0~9共10个类别。
训练集60000张样本，测试集10000张样本；单张图片尺寸为28×28像素，单通道灰度图，像素值范围0~1。
送入MLP前需要将二维图像展平为一维向量：$28\times28=784$维向量。

### 3.2 MLP网络结构
本实验采用两层全连接网络：
- 输入层：784个神经元（图像展平后的特征）
- 隐藏层：128个神经元，激活函数ReLU
  $$ReLU(x)=max(0,x)$$
  ReLU可以引入非线性，让网络拟合复杂映射，同时缓解梯度消失问题。
- 输出层：10个神经元，对应10个数字类别。
训练时使用交叉熵损失`CrossEntropyLoss`，该损失内部自带softmax，将输出映射为各类别概率。

### 3.3 优化算法
优化器：SGD（随机梯度下降）
超参数：学习率 $lr=0.01$
训练核心流程：
1. 梯度清零 `optimizer.zero_grad()`
2. 前向传播得到预测输出
3. 计算损失loss
4. 反向传播 `loss.backward()`，自动计算梯度
5. 优化器更新权重 `optimizer.step()`

### 3.4 模型评估
模型切换为eval模式，关闭梯度计算`torch.no_grad()`，在测试集上计算平均损失与分类准确率。
准确率 = 预测正确样本数 / 测试集总样本数。

## 四、实验代码
完整代码文件：`mlp_mnist.ipynb`
代码分为5个模块：
1. 包导入：导入torch、torchvision、数据集、优化器等；
2. 数据集加载：使用`torchvision.datasets.MNIST`，ToTensor归一化，DataLoader分批加载；
3. 网络定义：继承`nn.Module`，重写`__init__`与`forward`前向函数；
4. 训练循环：遍历训练集，完成梯度更新；
5. 测试评估：每轮训练结束后在测试集验证，输出loss和acc。

## 五、实验结果
训练轮次：30 epoch
每轮输出测试集loss、准确率acc
现象：训练初期损失快速下降、准确率快速上升；训练后期收敛变慢，准确率提升幅度变小。

## 六、结果分析
1. 收敛趋势：随着epoch增加，测试损失持续下降，准确率逐步上升，模型正常收敛；
2. 模型上限：单纯MLP不具备卷积的局部感受野、权值共享能力，无法利用图像空间相邻像素信息，因此MNIST上最终准确率一般在85%~90%左右，低于CNN；
3. 超参数影响：学习率0.01适中；如果学习率太大容易震荡不收敛，太小收敛速度极慢；
4. 过拟合观察：训练集效果一般优于测试集；本实验网络容量不大，过拟合现象不算严重。

## 七、实验总结
本次实验基于PyTorch搭建MLP完成MNIST手写数字分类，完整走完深度学习训练流水线。
通过实验理解了前向传播、损失计算、反向梯度传播、参数更新的完整机制；体会到激活函数带来非线性拟合能力。同时认识到全连接网络在图像任务上的短板，理解卷积网络的必要性，为后续CNN实验打下基础。
